# Esercizi C
Raccolta di prove pratiche ed esercizi svolti in linguaggio C.

## Argomenti trattati:
- Variabili, input/output e tipi base
- Condizioni if/else e costrutto switch
- Cicli for e while
- Array, vettori e calcolo medie
- Funzioni con parametri e valori di ritorno
- Stringhe e funzioni di libreria string.h
- Puntatori e passaggio per riferimento
- Strutture (struct e typedef)
- Operazioni basilari su file (fopen, fprintf)
